## Specs
- S1: User: "implementa los guardarails". Authorized grounding rule: "Para preguntas sobre documentación, abstenerse cuando no haya evidencia suficiente. Verificar que las referencias correspondan a fuentes disponibles." Do not require sources for greetings; structural citation validation does not establish semantic entailment. Test through both answer services.
- S2: "Limitar el conjunto de pregunta + historial + documentos antes de enviarlo al modelo." "Agregar cuotas por usuario; si faltan métricas de tokens, tratarlas como desconocidas, no como cero." Reject excess context rather than silently truncating it. Assumption: configurable local-process quotas keyed by verified connection user (shared connection means shared quota); no distributed/persistent quota guarantee or exact hidden Agent context accounting.
- S3: "Tratar preguntas y documentos recuperados como contenido no confiable, no como instrucciones." "Impedir que cambien las reglas o amplíen herramientas/permisos." Preserve independent caller authorization and approved Agent selection. Pattern detection and prompt boundaries are defense in depth, not proof of injection immunity.
- S4: User selected "Enmascarar datos personales": "reemplazar los datos personales detectados por etiquetas y continuar con el contenido protegido. Bloquear credenciales y secretos detectados." Scope: "correos, teléfonos, documentos de identidad y cuentas bancarias; no nombres propios." Cover input before UI storage/rendering, history, visible retrieved metadata and output, and explicit tracing attributes. Detection is bounded and heuristic, not comprehensive DLP.
- S5: "Aplicar un plazo total para recuperación y generación, con cancelación cuando el proveedor lo permita, y limitar solicitudes por usuario." Pass remaining deadline to supported provider statements; reject late results. No thread-based fake cancellation and no claim to interrupt unsupported synchronous Search calls.
- S6: Preserve existing hooks, progress ordering, safe errors, access checks and unaffected service behavior. Add rule identifiers and docs. Verify locally with deterministic fakes, pytest, Ruff and mypy, plus an isolated independent check; no live Snowflake calls.
- S7: User: "realiza de todos los cambios que tenemos pendientes, commit, push, PR, Merge". Chosen strategy: "Preparar PRs encadenados", then "Autorizar las dos excepciones". Publish diagnostics first and guardrails second, sequentially to main, linked to approved issue #32; caps 1,300/1,700 additions plus deletions; exclude the two local .venv skill symlinks. Do not bypass repository or GitHub checks.
